# CarCam Mediator
الوحدات: app (الواجهة) · core (الكشف + الخدمة) · camera (CameraX).
البناء سحابياً بدون Android Studio: انظر .github/workflows/build.yml
1. أنشئ مستودعاً على GitHub وارفع كل الملفات (مع مجلد .github).
2. تبويب Actions ← Build APK ← انتظر ✅ ← حمّل Artifact: CarCam-debug-apk.
3. فك الضغط وثبّت APK على هاتفك (اسمح بالتثبيت من مصدر غير معروف).
